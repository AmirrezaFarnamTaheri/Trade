    Backups
    Encrypted ledger recovery uses the existing protected-console workflow.
    Local recovery receipts
    
        
    Create an encrypted backup
    Use a pre-existing directory on an independent mounted volume. Enter the recovery passphrase only in the protected console.
    uv run gymctl --data <workspace-data> backup-once <ledger.db> <backup-directory>
    Restore to a new ledger
    The destination must not exist. Restoration verifies the ledger and leaves execution disarmed.
    uv run gymctl --data <workspace-data> restore-backup <archive.tgbak> <new-ledger.db>
