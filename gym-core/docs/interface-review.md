# Interface review

Reviewed 7 November 2026 across all ten destinations and five Paper research
sections. This is a source-based review. Browser policy denied local application
access; no rendered desktop/mobile/RTL, screen-reader or visual sign-off is claimed.

The maintained visual system uses warm light and charcoal dark themes, copper
selection, explicit paper/disarmed states, logical spacing, tabular decimals,
visible focus and reduced-motion support. Current contracts include stable saved
chart identities, separate transport/readiness indicators, currency-labeled nets,
HTML replay axes, explicit UTC formatting, theme-aware comparison strokes, neutral
equity curves, one-column phone forms and larger frequent-action touch targets.
These contracts still need rendered verification.

## Remaining source findings

P1 affects interpretation or access; P2 is recurring usability friction; P3 is
finishing work. These are design priorities, not security ratings.

| Priority | Destination | Remaining work and acceptance |
| --- | --- | --- |
| P1 | Workbench | Provide guided forms/readable results for common workflows beyond the grouped advanced action menu. Keep exact JSON under advanced inspection. Reuse validated service actions. |
| P1 | All curve reports | Add native freshness/coverage intervals to the reporting contract and segment curves accordingly. Do not guess that a time gap is missing coverage or imply continuous observation. |
| P2 | Saved runs | Lead with readiness, valuation freshness, fills, net/return and the main chart; group risk/cost/statistics/evidence into disclosures and link to the decision debugger. |
| P2 | Compare | Separate market/window and candidates from costs and action-specific validation. Verify the shared keyboard/time overlay inspector in a real browser; retain independent-start normalization and exact-time missing samples. |
| P2 | Charts | Make fill inspection accessible by keyboard/touch using native order records; verify tooltip bounds at edges. |
| P2 | Schedules | Put retry/catch-up/skip/interruption beside affected jobs. Recorded claims/progress must remain distinct from verified process liveness. |
| P2 | Markets | Verify quality filtering and spread/age sorting across the complete set and provide a compact row inspector. The pair column remains pinned during scrolling. |
| P2 | Portfolio | Replace comma-separated subsets with a compatible multi-market selector. Whole-quote selection, shared registry-generated strategy fields and all allocation controls are available; retain explicit quote/cash units. |
| P2 | Margin | Present rules → preview → replay as a three-stage flow, group collateral/debt/fees/equity, and show receipt age. Any protection diagram must distinguish modeled terms from placed protection. |
| P2 | Account journal | Lead with source, observation time, completeness/limits and per-asset balances; retain locked funds and unknown settlement. Do not sum unlike assets or label imported balances executor cash. |
| P2 | Offline ticket | Group intent, snapshot, limits and provenance; move privileged native JSON into advanced operations; retain canonical validation and synthetic labeling. |
| P2 | Venue rules | Search/filter effective and blocked rules, prioritizing affected markets before source/history. Dated presets must not imply current venue confirmation. |
| P3 | Backups | Present result/time/scope/integrity/restore evidence before raw receipts; retain protected-console passphrase handling. |
| P3 | AI connections | Separate connection setup from prompt use and standardize pending/error/recovery feedback. |
| P3 | Safety | Keep one global disarmed state, then group local evidence, missing qualification and console actions without repeated competing callouts. |
| P3 | All destinations | Standardize nearby pending/success/error messages, preserve last good results with a stale label, and never automatically retry ambiguous mutations. Complete localized display labels rather than exposing wire identifiers. |
