## 1. Findings that change the experiment

### The proposed final test has already shaped the strategy

The November 2025–November 2026 year was scored for Candidate B. The draft cites that loss and the gold rally as reasons to design S5, then proposes choosing the gateway on the same year. Freezing the new code cannot undo that information. Keep the year as a named bear-market stress replay. Freeze eligible arms, primary metric, costs, and fallback using chronological development folds. Confirm the chosen policy on a demonstrably untouched block if the research ledger establishes one, otherwise on a forward paper journal. Historical diagnostics can run immediately. Pre-register a minimum number of independent active blocks or a valid sequential rule for the journal. A calendar deadline alone says little about a sparse strategy. The motivating evidence also needs narrower language. The 320 losses in 337 markets refer to one hourly EMA configuration over **one week**. On the scheduled receipts, directional and spread losses both mattered. Candidate B's relative protection is economically interesting, but the obvious competitor is a simpler cash-heavy portfolio with similar exposure. A previous logistic veto on Binance dailies already lost to taking every proposal, −0.68% versus −0.59% mean net per five-day hold on 6,640 observations. It used a different venue, candidate definition and feature set. Make the new experiment identify the information that could reverse that result. ### The five-asset gold comparison assigns risk to the wrong instruments

The covariance helper sorts the symbols and returns its axis labels. The five-asset evaluation discards those labels. Its portfolio ends in **XRP, XAUT**, while its covariance axes end in **XAUT, XRP**. This swaps both assets' variances and their covariances with the rest of the portfolio. The four-asset instant-gate tuple happens to be sorted. The demonstrated mismatch applies to the five-asset evaluation, and its effect on historical performance remains unmeasured. Reindex both axes explicitly before every solve and require identical named targets when the input order is permuted. The same helper truncates arrays to the shortest length and pairs values by position. With intermittently missing bars, join on return start and end times before creating arrays. A fixture with equal-length series missing different days should detect the misalignment. ### The trade target and the optimizer currently price different things

The draft trains on an isolated round trip with fees and passes expected **net** bps to an optimizer that expects **decimal horizon returns** and already penalizes changes from current weights. The existing target protocol calls its field `expected_gross_bps`. A 20 bps forecast is 0.0020 at the optimizer boundary. Charging a full hypothetical round trip against an already-held position can cause avoidable churn. The diagram also promises fractional Kelly while the specified objective already sizes risk. [Optimizer interface](../../gym-core/src/gym/domain/convex_optimizer.py) · [Target protocol](../../gym-core/src/gym/domain/target_protocol.py)

Keep net outcome labels for entry diagnostics. Give the allocator a conditional **gross** return distribution over a declared clock, in a declared numeraire, and a separate incremental cost function for each feasible change of inventory. Estimate gross payoffs directly or reconstruct them from the same event receipts. Avoid adding a constant average fee back to labels whose fill costs depend on the outcome. Use one joint portfolio sizing rule initially. A fixture should reconcile cash → buy → hold → sell to the ledger, with zero execution cost on unchanged inventory, costs on both actual legs, and post-fee quantities respecting the charged asset. [Boyd et al., Multi-Period Trading via Convex Optimization](https://web.stanford.edu/~boyd/papers/cvx_portfolio.html)

### Causality and statistical checks need end-to-end tests

The existing Candidate B check credits old weights with close-to-close returns and computes new weights at the current close. The next close-to-close interval includes any gap before the next executable open. It also carries target weights forward without drifting them with asset prices. Its placebo uses the first asset's returns and exposure. Its causality lambda constructs a fresh EWMAC node for every price, so it never warms up. The pass Boolean omits the computed placebo. These are specific reasons to build a new portfolio evaluation path and to retain the previous packet as historical evidence. [Candidate B loop and checks](../../gym-core/scripts/instant_gate_check.py#L419)

Generate fills and NAV from positions, cash, reservations, fees and marks at event times. Perturb **every future input** after a cutoff, including other symbols, feature joins and book events. Assert byte-equivalent earlier eligibility, forecasts, intents, fills and NAV on a fixture that actually trades. Include a deliberately future-dependent feature as a positive control for the test. Build a portfolio placebo by shifting the joint intent stream within eligible regimes or permuting asset ranks within liquidity strata, preserving simultaneous market shocks and re-running costs and constraints. Draw the null to match the claim, whether timing or cross-sectional selection. Drive the written gate and its Boolean from the same named checks.

## 3. Improve the quantitative model

1. **Make diversification earn its place.** The 1.67× arithmetic assumes five comparably risky, equally skilled, equally weighted sleeves with the stated average correlation. Most proposed sleeves buy the same underlying crypto risk. A long-only trend can go flat during a crash. A BTC-residual ranking can still produce a high-beta long book. Estimate OOS marginal contribution after netting, market and gold betas, downside correlation, joint drawdowns, active-period overlap and sensitivity to removing each sleeve. Preserve valuable negative correlation. The draft's absolute-correlation cutoff could remove its best diversifier. Residualizing historical P&L can imply a short leg the portfolio cannot take. Test the executable portfolio that the transformed signals actually produce.
2. **Use an implementable event definition.** A decision needs instrument, side, proposal time, earliest arrival, expiry, quantity policy, horizon, exit priority and inventory state. When signals disagree, specify whether the fast model can add, reduce or only defer a slow holding. Evaluate held positions and compulsory exits even on ticks with no positive candidate. Define whether overlapping proposals are updates to one target or separate virtual lots. Cap aggregate holdings before fees. The same policy must generate both learning labels and trading outcomes.
3. **Make triple barriers executable.** Exclude movement before fill. Resolve two barriers touched in one candle using finer data only when covered, otherwise publish favorable and adverse bounds and require the conclusion to survive ambiguity. A gap through a stop can exit below the stop. Declare halt, expiry, partial-fill and terminal-censoring behavior. Estimate volatility at the declared bar frequency to avoid scaling an already horizon-adjusted volatility twice. For S3, reconcile its 36-hour maximum with a 72-hour label. For S4, compare the breakout against the *previous* 20 highs and compute pre-breakout compression before the release.
4. **Predict the value of a decision.** A 45% chance of gaining 300 bps against a 55% chance of losing 100 bps is worth +80 bps if those payoffs are net. The fixed 52% floor discards it. Conversely, a high hit rate can hide rare large losses. Estimate conditional win/loss magnitudes or shrunken return quantiles by horizon, liquidity and event type. Record fill probability and payoff conditional on fill jointly enough to preserve adverse selection. Compare adding risk, holding existing risk and waiting. Score rejected proposals in shadow using the same evidence as accepted ones. Track foregone winners, avoided losses, capital used and net uplift over the common candidate stream.
5. **Make inference match the time structure.** Outer evaluation is past-only expanding walk-forward. Select models and fit calibrators inside each outer training window. Split by whole UTC decision times across all assets. Purge by actual information and outcome spans in wall-clock time, including label maturity. Average inverse concurrency over each event's lifespan and declare whether weights target an event, asset or date distribution. Calibrate to the intended deployment population. The current CPCV helper partitions row indices, and the PBO helper creates one-point daily intervals. Reserve the latter for selection-instability diagnostics on aligned return series. Record tied ranks fairly. [CPCV and PBO implementations](../../gym-core/src/gym/domain/statistical_inference.py) · [Original PBO paper](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)
6. **Set an economic primary endpoint and estimate its power.** Use paired daily net portfolio differences against a predeclared comparator with identical starting wealth, execution and risk budget. Report a block-bootstrap interval, active-risk/exposure-matched comparison, excess return, drawdown duration, expected shortfall with tail count, and turnover. Show Brier skill against a training-only base-rate forecast, log loss, reliability slope/intercept, and calibration near the trade threshold. At 20% prevalence a constant 0.20 forecast scores 0.16 Brier with zero ranking skill. Daily aggregation removes duplicate cross-sectional observations but preserves serial dependence. The current power helper draws individual observations with replacement. Simulate contiguous or stationary date blocks and estimate power for the *whole* promotion rule. As an illustration, with 30 trials and three years of IID daily observations, the current helper's normal-moment convention needs about **2.15 annualized Sharpe** for DSR 0.95. This is an approximation, not an observed return. State which outcomes imply rejection and which imply insufficient information. [Gate and power helpers](../../gym-core/src/gym/domain/signal_gatekeeper.py)
7. **Use honest controls.** Include cash in the reporting numeraire, Candidate B recomputed on the same ledger, fixed equal-risk sleeves, static gold, and a rule that matches the gateway's exposure or acceptance rate using development data. Compare every arm on the same eligible timestamps and capital. Fixed S1 is a prespecified baseline. A best-single-sleeve baseline requires inner-fold selection. Mode A's decayed Sharpe softmax is an adaptive heuristic and its calibrator is supervised. Specify the score combining consensus and quorum, the update after outcome maturity, shrinkage at small counts and a normalized capped-weight rule that handles sparse availability. Give the equal-weight control the same execution overlay.

## 5. Three research bets beyond the draft

| Hypothesis | Cheapest discriminating experiment | Evidence to stop |
|---|---|---|
| **Waiting or internally netting signals is worth more than forecasting another direction.** Fast and slow sleeves can generate opposing changes before settlement. | Freeze all forecasts. Compare immediate turnover with a hysteresis band and an expiry-aware delay. Attribute saved fees, lost alpha and reduced market impact separately. Map value against forecast half-life. | Gains disappear after charging missed moves or fail against a simple fixed turnover band on paired dates. |
| **The local venue dislocation is tradable only when liquidity replenishes.** A large apparent premium can be an old print or unavailable depth. | In timestamp-matched paper data, condition convergence on quote freshness, replenishment after a trade and tradable size. Compare against the same premium without replenishment. Use a leave-one-venue-out reference and score both legs, failed hedges and the inventory reset. | Profit exists only at mid-prices, after clock skew, or before charging the return of inventory to its starting venue. |
| **The value of 30-minute data is a better order, even when it adds no direction.** | Replay the exact same accepted directional intents through baseline and S6 execution. Measure shortfall saved per intended unit, adverse fills avoided, profitable moves missed, and delay sensitivity. Break out volume drought and fresh-book states. | A fill-only improvement vanishes on all intended orders or depends on one market episode. |

## 6. Delivery order and acceptance

1. **Prove the measuring instrument.** Produce the point-in-time coverage report, repair and independently check the allocator, and replay one frozen strategy through a self-financing shared ledger. Acceptance requires objective agreement, invariant cash/units, defensible timestamps, cost-once accounting and an explicit uncovered state.
2. **Prove the simplest economic hypothesis.** Compare cash, exposure-matched trend, static gold, and a small fixed ensemble on identical data. Report paired net uplift, drawdown and risk attribution. Run leave-one-sleeve-out tests and adverse fill bounds. If the proposed diversification vanishes under equal risk or costs, retire or redesign the sleeve before adding a gateway.
3. **Test the gateway's incremental value.** Freeze one candidate stream. Compare equal-rule weights, the adaptive vote and one calibrated logistic model. Predeclare the decision metric, multiplicity accounting, minimum meaningful improvement and fallback. Permit no-trade and insufficient-evidence outcomes. A historical model win earns a frozen paper comparison.
4. **Expand where evidence pays for complexity.** Admit HGBT, separate fast coefficients, direct ML, route selection and S6 one at a time only after their stated development criteria. Keep execution-native venue evidence distinct from fee counterfactuals. The endpoint of this roadmap is a measured paper policy with reproducible failure conditions and a disarmed executor.

## 8. Scope of the first experiment

**Primary question.** For the same eligible Wallex spot entry proposals and opening holdings, does a frozen logistic veto improve net portfolio wealth over the fixed rule at the declared risk budget? My recommended primary measure is the paired difference in ending USDT liquidation wealth per unit of equal starting capital, with open or unpriceable inventory disclosed. Use aligned daily NAV differences for uncertainty and risk reporting. Freeze a minimum economically useful improvement, a risk tolerance, the evaluation interval and an execution-cost sensitivity from development evidence before scoring. If inventory cannot be liquidated within the evidence, carry bounds into the comparison. A model that wins only under the favorable bound has an inconclusive result.

| Disposition | Work included | Release condition |
|---|---|---|
| First paper evaluation | Wallex spot long/flat, one self-financing account, the slow sleeves supported by data, fixed controls and a veto-only logistic challenger. Compare all arms under the same position-sizing and execution policies. An all-cash outcome is valid. | A second reviewer can reproduce the decision from the frozen manifest, policy, inputs, fills and ledger. The simple strategy must also justify its absolute risk against cash. |

## 9. Small details that materially change outcomes

| Contract to specify | Boundary example and expected behavior |
|---|---|
| Information arrival at a bar boundary | A 6h close and the next bar's first trade can both carry 12:00. A signal that processes the close after that first trade cannot buy that print. Order by receipt, processing, simulated arrival and eligible market event, with a deterministic tie rule. Where candles cannot resolve the order, report the next-open convention and a delayed-fill sensitivity. |
| Expiry, cancellation and forced exit | An entry that expires at the instant a fill arrives needs a deterministic exchange-event ordering or bounded outcomes. An unacknowledged cancellation still reserves funds and quantity. A stop or mandatory exit outranks an entry veto. New purchases may freeze while held risk continues through the exit policy. |
| Repeat signals on different clocks | A daily score read twelve times by a 2h loop is one forecast vintage. Carry its observation time and expiry. Emit a fresh order only when required target units change after subtracting holdings and still-working orders. Preserve the same identity on restart. |
| Signal scaling and missing states | The existing EWMAC node returns bounded scores on a ±20 scale, volatility-normalizes internally, and warms up at half its longest span. The draft wants ±1, Yang–Zhang volatility and 128 bars. Specify one normalization and an explicit warm-up mask. A legitimate neutral score, an absent sleeve and a veto are three distinct values. A volatility floor can stabilize arithmetic while observations remain ineligible. | Cross-sectional rankings and breadth | Exclude cash and gold from crypto breadth. Record the eligible numerator and denominator, and suppress the statistic below a registered minimum. | Voting arithmetic and model schema | Two available sleeves capped at 0.40 each cannot sum to 1. Explicitly retain the remainder as abstention or define a different sparse-coverage policy. Two inexpensive falsification tests belong before the model race. First, run the entire selector on synthetic panels with common market shocks, realistic missingness and no conditional edge, then on otherwise identical panels with a planted, feasible edge of known sign and size. Measure how often the full procedure promotes noise and how often it recovers the planted effect after costs. Keep these receipts labeled synthetic. Second, rebuild the fast sleeves at prespecified alternative UTC bucket offsets on common history. A strategy that disappears after shifting a six-hour boundary by one hour needs either an economic explanation for the original boundary or weaker evidence status. Report every offset as a sensitivity and leave the registered production offset fixed.

## 10. Decision record and completion criteria

**Freeze before the first score.** Record code and data vintage, universe and eligibility policy, bar-source policy, all fitted transforms, arm IDs, candidate IDs, treatment of folds and inherited inventory, payoff horizon, fees, starting wealth, and the single primary comparator. Give historical development, the previously seen stress year and independent confirmation separate evidence IDs. A renamed strategy or a new symbol trading the same market regime does not make previously observed information fresh. Specify whether a comparison starts from cash or inherits a common book and use the same choice for all arms.

For a walk-forward or prospective run, freeze the *learning procedure* as well. Specify refit dates, trailing training window, outcome-maturity cutoff, calibration refresh and expiry. Log the model version attached to the decision when it was made. If a refit fails, apply a declared abstention or qualified fallback to new entries and continue the inventory exit policy. Evaluate this same procedure historically. A hindsight choice between a frozen model and rolling retraining creates another selectable strategy.

**Resolve contradictions in the draft.** Use one naming scheme for the voting, logistic and optional ML-peer arms. List each selectable fit separately. The nominal five-way matrix contains two learned estimators in its fifth row if both run. Keep the veto-only test, sizing test and execution test separate so their contributions can be measured. Specify portfolio-wide versus instrument-local defensive signals, and freeze the action when inputs are missing. If logistic loses to voting, voting must still clear its own economic and data requirements to be selected.

| Verdict | Evidence and consequence |
|---|---|
| Invalid run | A causal, unit, price-source, covariance-axis or ledger invariant fails. Quarantine the receipt, correct the cause and rerun dependent comparisons under a new version. |
| Inconclusive | The evidence cannot distinguish a material improvement from noise or execution ambiguity. Show the missing coverage, paired interval or width of the fill bounds that prevents a decision. Collect the observations most likely to resolve it. |
| Retire the increment | Adequate evidence rejects the predeclared economically useful uplift, or the increment breaches the risk budget. Retain the simplest independently qualified paper comparator and archive the unsuccessful arm. |
| Advance to independent paper evaluation | The frozen arm clears its development criteria, survives the named stress tests and has a reproducible ledger. Freeze it for an independently consumed test or prospective paper journal. Record that later verdict under its own evidence ID. |

For sign-off, request four artifacts from implementation: a dated coverage and bar-parity report, a reference-solver and ledger reconciliation, an arm-by-arm paired comparison with uncertainty and exposure, and a machine-readable decision receipt showing every guard and missing observation. The experiment is useful if it identifies which layer creates or destroys value, including when the economically justified action is to remain in cash.

## 11. Measured bottlenecks and optimization priorities

**First engineering choice.** Fix the candle access path and share immutable market calculations across arms. On the existing four-asset Candidate B development replay, these two in-memory prototypes together reduced median elapsed time from **8.44 s to 0.73 s**, about **11.5×**. All three paths returned the same report dictionary on 1,281 development return days. This is a speed comparison for an existing evaluator with the limitations in §1. The proposed 20-asset ML ensemble has no end-to-end timing yet.

### Scaling the proposed ensemble

1. **Share only causally reusable work.** Decode each instrument and requested time range once, normalize timestamps once, and generate all eligible timeframes from that stream. Compute deterministic features on unique decision timestamps and map candidates to those timestamps. Reuse a label only across arms with identical entry, exit, costs and horizon. Key derived data by source vintage, bar convention, instrument epoch and feature version. Fit scaling, feature selection, payoffs and calibration separately inside each applicable fold. Test that changing a future row invalidates the right partition and leaves earlier decisions intact.
2. **Control memory before adding workers.** A dense 180k × 16 float64 matrix occupies about **22 MiB** before labels, masks, Python objects, calibration copies and estimator state. Store typed arrays once, pass integer indices, stream one fold's working data, and retain only receipts needed for reproducibility. Measure peak working set and cache bytes. Once data is shared correctly, parallelize independent arms or outer folds with a bounded worker count. Benchmark worker counts and numerical-library threads together. Parallel order processing within a shared account can change which order consumes cash or a print.
3. **Scale the expensive scientific checks deliberately.** Construct label overlap counts with a sweep over interval starts and ends. For a bounded triple-barrier horizon, pre-index entry positions and scan only eligible future bars through first touch or expiry. Reuse chronological event arrays for placebos while recomputing each path's feasible fills, cash and costs. Count unique transformations when a short history makes sampled shifts repeat. Profile logistic fit, calibration, bootstrap and portfolio placebos separately on the eventual model inputs. The relative cost of those stages remains open.
4. **Keep market coverage stable while improving speed.** Experiment 0 loads at most 8,000 book rows and 12,000 trades per symbol. A row cap represents different elapsed periods across liquid and thin markets. For a 25-day execution claim, stream bounded time slices with a stable cursor, matching book/trade boundaries, warm-up, queue state and outstanding deadlines. Retain enough following data to score markouts while keeping it invisible to trading decisions. Verify that changing the chunk size preserves fills and elapsed coverage. [Current window loader](../../gym-core/scripts/experiment_0.py#L51)

**Performance acceptance.** At the next implementation milestone, retain one small exact-parity fixture, one representative development replay, and one target-size 20-asset run. Record input rows, valid dates, orders, fills, fit count, elapsed time per stage, peak memory and cache size. Compare cold and warm runs on the same data vintage and machine. Check fold membership, decision-time forecasts within a declared numerical tolerance, discrete intents, exact Decimal cash and fees, order results, NAV and the gate verdict. Where a financial correction intentionally changes outputs, first establish the corrected reference, then benchmark the optimization against it. Prioritize the keyed loader, shared market features and corrected CV splitter for the core experiment. Timestamp-indexed execution and volume-bucket batching matter most when the archive replay and S6 enter scope.
